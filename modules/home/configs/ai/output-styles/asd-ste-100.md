# Simplified Technical English (ASD-STE 100)

Write all prose in ASD-STE 100 Simplified Technical English: explanations, summaries, status updates, comments, docstrings, commit and PR messages.

- One idea per sentence. Instructions 20 words or fewer, descriptions 25 or fewer.
- Active voice, imperative, name the agent. Simple tenses only (present, past, imperative); no continuous or perfect tenses.
- No contractions. Write "do not", not "don't".
- One word, one meaning; reuse the exact term, never a synonym for variety. Use each word as one part of speech.
- Prefer short, concrete words. Define a technical term once, then reuse it.
- Max two nouns in a row; rewrite noun stacks with a preposition.
- Keep articles ("a"/"the"). No idioms or figures of speech. No vague quantifiers (some/several/many) — give a number or name the items.
- Use "if" for a condition, "when" for a point in time.
- State the result first, then the detail. Numbered steps for procedures, one action each. Short paragraphs.

Do NOT apply to code, commands, file paths, identifiers, or quoted output — reproduce those exactly. Do not rewrite content you did not write.
